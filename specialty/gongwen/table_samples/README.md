# 表样库（table_samples）

省定附表的版式样本。写"窗口指导"类材料需要附表时，先来这里找空表和填写示例。

## 窗口指导项目审核表（省定格式）

- 来源：省发改委"窗口指导"项目审核意见附表（2026-11，第四批），用户微信收文原件归纳。
- 空表：`窗口指导项目审核表-省定空表.xls`（sheet"汇总"，序号 1~15 行已预置）。
- 示例：`窗口指导项目审核表-填写示例（廊坊三项目）.xls`——算粒基地、中利之星、悠联三个项目的填写样例。

### 列结构（13 列，一项目一行）

| 列 | 字段 | 填写口径 |
|---|---|---|
| 1 | 序号 | 空表已预置，不动 |
| 2 | 项目名称 | 全称 |
| 3 | 建设内容（简述） | 规模、栋数、机柜/IT容量、建设时序 |
| 4 | 建设主体 | 公司名称（含母子公司关系） |
| 5 | 投资主体 | 公司名称 |
| 6 | 运营主体 | 公司名称（持牌情况） |
| 7 | 应用需求 | 服务模式 + 主要客户/承载业务 |
| 8 | 国产生态 | 芯片型号、智算规模、国产化率 |
| 9 | 设计PUE | 数值（可注工况） |
| 10 | 设计WUE | 数值 |
| 11 | 资金筹措 | 总投资、资本金/自有资金、融资安排及到位情况 |
| 12 | 经济效益 | 营收、收益率、回收期（无则注明"原文未列"） |
| 13 | 意见 | 市级审核意见，**留待用户审定** |

### 从"8 方面"审核意见正文映射到本表

- 区域布局 → 不单列，选址信息并入"建设内容"或"项目名称"备注；
- 主体实力 → 拆填第 4/5/6 列；
- 应用需求 → 第 7 列；
- 国产生态 → 第 8 列；
- 节能节水 → 第 9/10 列（绿电占比无列，可并入第 8 列或舍弃）；
- 资金筹措 → 第 11 列；
- 经济效益 → 第 12 列；
- 建设方案 → 并入第 3 列；
- 审核意见 → 第 13 列，待用户填。

### 规矩

- 数据一律照抄项目单位报送材料，没有的标"原文未提及/未列"，不编；
- 格式沿用空表原样式，用 xlrd + xlutils.copy 写入（xlwt 写新表会丢样式）；
- 本目录含项目信息，只在本机用，不外传。
